# CodeAlpha E-Commerce Sales Analysis

## Project Overview

This project was completed as part of my CodeAlpha Data Analytics Internship.

The project focuses on Exploratory Data Analysis (EDA) of an e-commerce sales dataset using Microsoft Excel. The analysis was carried out to understand the structure of the dataset, examine sales and profit patterns, identify data quality issues, and generate meaningful insights.

## Objectives

- Understand the structure and variables in the dataset
- Check for missing values and repeated Order IDs
- Analyze sales amount, quantity, and profit
- Compare performance across product categories
- Analyze payment methods
- Examine sub-category performance
- Identify loss-making sub-categories
- Summarize key findings from the analysis

## Tools Used

- Microsoft Excel
- PivotTables
- Excel formulas
- GitHub

## Dataset

The dataset contains 1,500 records and 7 variables:

- Order ID
- Amount
- Profit
- Quantity
- Category
- Sub-Category
- PaymentMode

## Key Findings

- No missing values were identified across the 1,500 records.
- Clothing had the highest number of records.
- Electronics had the highest total amount and average amount per record.
- COD was the most frequently used payment method.
- Printers generated the highest total profit among the sub-categories.
- Several sub-categories recorded negative total profit, including Furnishings, Electronic Games, Kurti, Skirt, and Leggings.
- Transaction volume did not always correspond to higher sales value or profitability.
